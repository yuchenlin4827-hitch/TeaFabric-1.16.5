怎麼啟動

  1. 把整個 zip 解壓縮，從解壓出來的資料夾啟動（web 資料夾要和程式放在一起）。
  2. Windows：雙擊 TeaFabric.exe。第一次如果出現「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。
  3. macOS：Apple 晶片用 TeaFabric-mac-apple-silicon，Intel 用 TeaFabric-mac-intel。第一次在 Finder 對它按右鍵 →「打開」。
  4. Linux：在終端機執行 ./TeaFabric-linux。
  5. 程式會用預設瀏覽器打開 http://127.0.0.1:47265/。玩的時候不要關閉它的視窗。瀏覽器需要 Chrome / Edge 119+、Firefox 120+ 或 Safari 18.2+。
